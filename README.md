# AI Inference Lab

## Overview

AI Inference Lab is a performance analysis and benchmarking project focused on understanding the behavior of transformer-based Large Language Models (LLMs) during inference.

The project investigates the impact of quantization techniques, context length scaling, token generation throughput, latency, and GPU memory utilization using CUDA-accelerated inference pipelines.

## Objectives

* Analyze FP16 and INT8 inference performance
* Measure token generation throughput
* Benchmark transformer latency
* Study context-length scaling behavior
* Evaluate GPU memory consumption
* Understand inference optimization trade-offs

## Technologies

* Python
* PyTorch
* CUDA
* Hugging Face Transformers
* TinyLlama
* NVIDIA RTX GPU

## Experiments

### Quantization Benchmarking

Comparison of FP16 and INT8 inference performance, memory consumption, and latency.

### Token Generation Benchmarking

Measurement of tokens-per-second throughput across different workloads.

### Context Length Scaling Analysis

Investigation of how increasing context size impacts inference speed and GPU memory utilization.

### GPU Profiling

Monitoring memory usage and computational efficiency during transformer inference.
